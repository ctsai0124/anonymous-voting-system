# 🏫 學校教評會線上/紙本雙軌無記名投票系統 (School Teacher Review Committee Voting System)

> 專為台灣各級學校人事室打造的教評會與各類委員會選舉系統。整合 WebHR 名冊解析、教評會法定組成試算、紙本選票與簽收清冊產製、GAS 雙工作表物理切斷匿名線上投票、開票計票單及電子公文簽案自動化。

## ✨ 核心特色與亮點

### 1. 🧮 教評會委員總人數與法定比例試算（參考 [committee.leotsai.me](https://committee.leotsai.me/)）
* 依據《高級中等以下學校教師評審委員會設置辦法》第 3 條規範設計。
* 輸入委員總額（5~19人）與教師會成立狀態，自動計算：
  - 👑 **當然委員**（校長、家長會代表、教師會代表）
  - 🗳️ **選任 (票選) 委員**（全體教師票選）
  - ⚖️ **未兼行政教師下限** ($\ge 1/2$)
  - 🚻 **任一性別下限** ($\ge 1/3$)
* 提供「一鍵帶入選任人數為圈選上限」便捷按鈕。

### 2. 📥 WebHR 名冊一鍵解析與智慧過濾
* 支援 WebHR 匯出之原始 `職員名籍冊`（`.xlsx`, `.xls`, `.csv`）或 Word 表格全選貼上解析。
* 💡 **WebHR 產製路徑**：`WebHR 系統 ➡️ 個人資料 ➡️ 個人基本資料 ➡️ 報表 ➡️ 職員名籍冊 (報表格式選 EXCEL)`。
* 🛡️ **自動法規過濾**：自動排除代理/代課教師與非教師人員（校長、幹事、護理師、工友等）。
* 🔑 **自動生成通行碼**：自動合成 `身分證後4碼 + 生日MMDD 4碼` 共 8 碼無記名驗證碼。

### 3. 📄 4 大制式行政文書全流程自動產製 (A4 一鍵列印)
* **📄 紙本選票單 (A4)**：包含「壹、說明一～五點條文」、圈選上限、廢票門檻、起訖時間、發票人與監票人簽章欄。
* **✍️ 選票簽收清冊 (A4)**：提供發票現場供全校同仁簽名領票用。
* **📊 開票計票單與當選名冊 (A4)**：含候選人計票列、計票人/監票人簽章欄、正取 (8名) / 備取 (5名) 當選名冊、同票抽籤註記 `(抽)` 與未兼行政/性別比例法規自我檢核欄。
* **✉️ 電子公文簽案 (簽稿)**：線上投票自動結案後，發送符合全台學校人事室標準之「教評會委員改選簽案」至管理者信箱，可直接複製貼上至學校公文系統。

### 4. 🛡️ 雙工作表物理切斷 (Physical Data Isolation) 絕對無記名
* **Sheet A (Voter_Registry)**：僅儲存通行碼與是否已投票布林值。
* **Sheet B (Vote_Results)**：僅儲存加密投票活動 ID 與圈選陣列，不寫入時間戳記。
* **LockService 獨佔鎖**：採用 Google Apps Script 10 秒獨佔鎖機制，徹底防止搶票與並發寫入碰撞。
